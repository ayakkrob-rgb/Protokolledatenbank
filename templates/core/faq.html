So funktioniert's

Die wichtigsten Fragen rund um Freischaltung, Bezahlung und Erstattung.

Wer kann die Protokolldatenbank nutzen? {% icon "chevron-down" %}
Alle Studierenden mit einer gültigen studentischen E-Mail-Adresse{% if site.domain_list %} (erlaubt: {{ site.domain_list|join:", " }}){% endif %}. Nach der Registrierung schicken wir dir einen Bestätigungslink – erst danach kannst du Protokolle ansehen.
Was kostet der Zugang? {% icon "chevron-down" %}
Ein Paket kostet {{ site.price|euro }}. Damit schaltest du die Protokolle von bis zu {{ site.max_examiners_per_purchase }} Prüfern einer Prüfung (z. B. deiner Prüfungskommission im Physikum) frei – inklusive aller Protokolle, die später noch zu diesen Prüfern hinzukommen.{% if site.access_duration_days %} Der Zugriff gilt {{ site.access_duration_days }} Tage.{% endif %}
Wie bekomme ich mein Geld zurück? {% icon "chevron-down" %}
Lade nach deiner Prüfung dein eigenes Gedächtnisprotokoll zur gekauften Prüfung hoch. Wir erstatten dir dann automatisch {{ site.refund_amount|euro }} auf das Zahlungsmittel, mit dem du bezahlt hast{% if site.require_upload_approval %} – sobald die Fachschaft dein Protokoll kurz gesichtet hat{% endif %}. Pro Paket gibt es eine Erstattung. Je nach Bank dauert die Gutschrift einige Werktage.
Kann ich später noch Prüfer hinzufügen? {% icon "chevron-down" %}
Ja. Hast du weniger als {{ site.max_examiners_per_purchase }} Prüfer gewählt, kannst du die freien Plätze unter „Mein Bereich“ jederzeit kostenlos auffüllen.
Mein Prüfer ist nicht in der Liste – was nun? {% icon "chevron-down" %}
Dann gibt es zu ihm noch keine Protokolle. Wenn du nach deiner Prüfung ein Protokoll hochlädst, kannst du den Prüfer einfach neu eintragen – er wird automatisch angelegt.
Wie lade ich ein Protokoll hoch? {% icon "chevron-down" %}
Unter „Protokoll hochladen“ wählst du die Prüfung und das Datum aus. Für jeden Prüfer kannst du einen eigenen Abschnitt anlegen und den Text direkt eintippen oder eine Datei (z. B. PDF oder Word) hochladen.
Wie wird bezahlt? {% icon "chevron-down" %}
Die Zahlung läuft sicher über unseren Zahlungsdienstleister Stripe (z. B. Karte, Apple Pay, Google Pay oder weitere Methoden). Deine Zahlungsdaten erhalten wir nicht.
Darf ich Protokolle weitergeben? {% icon "chevron-down" %}
Nein. Die Protokolle sind nur für deinen persönlichen Gebrauch bestimmt.{% if site.watermark_downloads %} Heruntergeladene PDFs werden deshalb mit deiner E-Mail-Adresse gekennzeichnet.{% endif %}
