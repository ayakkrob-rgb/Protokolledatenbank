{% if section.key == "zahlungen" %}

{% icon "card" %} Stripe anbinden – in 4 Schritten

  1. Im Stripe-Dashboard → Entwickler → API-Schlüssel den Geheimschlüssel (sk_live_… bzw. zum Testen sk_test_…) kopieren und links eintragen.
  2. Unter Entwickler → Webhooks einen Endpunkt mit dieser Adresse anlegen:
    Ereignisse auswählen:
    • checkout.session.completed
    • checkout.session.async_payment_succeeded
    • checkout.session.async_payment_failed
    • checkout.session.expired
    • charge.refunded
  3. Das Signaturgeheimnis (whsec_…) des Webhooks links eintragen.
  4. Zahlungsmodus auf Stripe stellen, speichern und „Verbindung testen“.

Aktueller Schlüssel: {% if stripe_mode == "live" %}{% badge "LIVE" "success" %}{% elif stripe_mode == "test" %}{% badge "Testmodus" "warning" %}{% elif stripe_mode %}{% badge stripe_mode %}{% else %}{% badge "keiner hinterlegt" %}{% endif %}

Hinweis zu Gebühren: Stripe behält bei einer Erstattung seine Gebühr der ursprünglichen Zahlung ein. Bei {{ site.price|euro }} Preis und {{ site.refund_amount|euro }} Erstattung bleibt nach Gebühren nur ein kleiner Betrag übrig.
